## 🧠 Core Technology


MasterAI is built upon **Game Theory (GTO) + Deep Learning + Reinforcement Learning** and employs the following cutting-edge technologies:


| Technology | Description |
| :--- | :--- |
| **CFR Algorithm** |
Counterfactual Regret Minimization, computing Nash equilibrium strategies |
| **Monte Carlo Sampling** | Approximating optimal action values ​​via extensive MC sampling |
| **Neural Network Valuation** | Offline solving + online continuous re-solving |
| **Nash Equilibrium Strategy** | GTO optimal strategy; unexploitable |


### Architecture Components


- **Offline Component**: Solves stochastic poker scenarios; trains neural networks to predict hand values
- **Online Component**: Uses continuous re-solving algorithms to dynamically select optimal actions
